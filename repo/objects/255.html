Chatbot Sanelma
Date added:  2013-12-31 13:31:17
Modified:        2013-12-31 13:32:57
Museum/site: Finnish National Gallery Country: Finland Developers: FNG: Marjatta Levanto Riikka Haapalainen UIAH: Joanna Saad-Sulonen, Marjo Mäenpää, Tarja Toikka Eva-Kaisa Nojonen, Teriina Lindblom, Leena Saarinen, Jyrki Heinonen Sponsor partnerships: Submitted by: University of Art and Design, Medialab Project website: http://mlab.uiah.fi/mummi/sanelma Project status: idea Project type: Stationary/Fixed media Start year: 2003 End year: 2005 Summary: Project is an artificial intelligence (AI) application. Sanelma is an educational communication environment and it utilizes vocabulary, which is based on prepared key/value pairs. Definition: artificial intelligence (AI) is the study of how to create a computer, that can "think" like a human being. Intentions: Sanelma' s intention is to attract, engage, motivate, activate and satisfy the user. The user dives into Helsinki of 1930, with its city-optimism, urban culture with jazz, silk stockings, rhythm, machines; as well as the shift of the meaning of art: from the creator of national unity to individualism, modernism, kubism. Tech spec Programming Environment Java 1.4 JDK Runs as an application in the computer's Java Virtual Machine (JVM) thereby needs Java Runtime Environment (JRE). Application has a graphical user interface (Swing). Comments: A Concept For Chatbot "Sanelma" : building engaging relationship between the work of art and the exhibition visitor. Our chatbot is a virtual person, with whom the user communicates in writing (typing on a keyboard) in the context of a museum exhibition. The chatbot is not a teacher nor a museum guide, but a fictional, yet realistic person belonging to the era of the painting it is associated with.
