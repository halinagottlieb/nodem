LAMB/FÖLIS - Learning, Access, MoBility in digital communication of archaeological cultural heritage
Date added:  2014-02-02 12:41:35
Modified:        2014-02-02 12:41:35
Author / Creator Kari Uotila
Organization/company: Muuritutkimus Company, Finland Presenter: Kari Uotila Type of project: Mobile information system framework While a considerable number of mobile computing applications for cultural and archaeological heritage presentation have been developed, the characteristics of archaeological information and processes of transferring it to the mobile context have received considerably little attention. The question of how the archaeological data makes information suitable for general public audiences is discussed in the context of an on-going R&D project LAMB (in Finnish Fölis) set in south western Finland. The focus of the project is in moving heritage experience and guidance to the actual sites using a system, which is capable of serving both schools and other user groups same time. The project began in 2001 and has proceeded in three major sub-projects in Naantali, Archipelago Sea and the latest one in several rural sites north of Turku. The project has studied, developed and evaluated several different approaches starting from standalone applications on palmtop computers, Tablet PCs, smart phones to modern small light-weight portable tablet computers. The emphasis is on building a system, which can be updated and maintained on site by the local staff without extensive technical knowledge. The software is based on open source components. At the moment, the latest development cycle uses a modular Java-based client for providing its users a dynamic, multifaceted experience on a cultural heritage site using a broad array of media. The project presentation discusses the lessons learned during the seven years of the project and discusses critical success factors for communicating an archaeological cultural heritage site using a mobile digital device.
