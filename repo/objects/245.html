Portable heritage in Medieval Naantali
Date added:  2013-12-31 13:04:24
Modified:        2013-12-31 13:04:35
Museum/site: Naantali Museum Country: Finland Developers: Kari Uotila, Isto Vatanen, Hannele Lehtonen Sponsor partnerships: Submited by: Muuritutkimus ky Project website: -- Project status: idea Project type: Portable/Wireless Application Start year: 2003 End year: 2005 Summary: Project is about building a tablet-pc based educational portable multimedia presentation system for the Museum of Naantali. Emphasis is in easily usable, media-rich implementation on relatively affordable and easy to maintain platform. Intentions: In the first phase intended for elementary school pupils, later for older students. Plans to make the system available for tourists are also in course. Tech spec: Selfstanding tablet-pc based implementation based on GPS positioning and Wlan-connection for maintenance purposes. Comments: Project is in prototype implementation phase proceeding to full implementation during the last three quarters of 2004.
