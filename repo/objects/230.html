Omnibus data bank
Date added:  2013-12-31 11:38:01
Modified:        2013-12-31 12:36:34
Museum/site: Helsinki City Museum Country: Finland Developers: Helsinki City Museum, Grafimedia Sponsor partnerships: Submitted by: Helsinki City Museum Project website: http:// Project status: completed Project type: Web based/Virtual Application Start year: 2001 End year: 2002 Summary: The material of Omnibus is collected from Helsinki City Museum's own databases, containing art, archive material, photographs, objects and building inventory. Curators in City Museum the planned the structure and the content of Omnibus. A graphic interface is designed to make the searching easy and appealing for the users. The interface is made by Grafimedia. One of the main aims of Omnibus is to show the public the basic work in museums, cataloguing and managing of the museum collections. Intentions Omnibus opened in December 2002 at the Tram Museum, owned by Helsinki City Museum. It is the second data bank made by the City Museum. The first one started in the year 2000 at the School Museum. The data bank supports the exhibition, giving visitors more information of the individual objects. The user can also browse the data bank without actually going to the exhibition. In the future plans Helsinki City Museum intends to put data banks on the internet. For the moment the strict safety measures of the Helsinki City administration prevent the internet use. The data banks have interested especially teachers. They contain suitable material for schools which are using internet in the curriculum. Tech spec: Omnibus data bank is based on Maria/Media Vu -media management and archiving application. Data is stored in full-text BRS / Search-database. Totally Omnibus contains nearly 600 data files in the database. The size of the small thumbnail pictures is 128 pixels (4 kb) and larger preview pictures 512 pixels (45 kb). Omnibus runs in NT-server and is accessible with ordinary browser-compatible workstation. The application is designed for web use. All the navigation is done by the mouse, so the user doesn't necessarily need keyboard. For the educational purposes there is larger second screen connected to the workstation at the Tram Museum. Comments: Computer data bank "Omnibus" tells the history of urban transport in Helsinki, from mid-19th century to the present day. The material in Omnibus is divided into the four time periods. After selecting the preferred time period the user can choose material from different themes (the bus stop sign, on the left side of the screen), for example the buses (=linja-autot) or the trams (=raitiovaunut). Each theme contains 10-15 data files from the Helsinki City Museum's data bases. Each file includes the picture and the basic cataloguing information. The user clicks the files open from the small thumbnail pictures (on the left side of the screen). The user can also browse all the material from one theme without going back and forth to the time line. The demo will start by clicking the etusivu.html -file. NB: There is only one data file in the demo. So, you get the same tram picture every time you try to open a new data file.
