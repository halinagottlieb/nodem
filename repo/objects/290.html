Project Holoship
Date added:  2014-02-02 12:24:48
Modified:        2014-02-02 12:25:14
Author / Creator Benjamin Asmussen
Organization/company: Danish Maritime Museum, Denmark Presenter: Benjamin Asmussen Type of project: Exhibition - augmented reality - an interactive maritime learning environment The Holoship project is a reality-augmented interactive maritime learning enviroment. It offers schools classes and other visitors the opportunity to experience the life of a sailor from the 18th to 21th century. Independent of the often bad Scandinavian weather, the Holoship will, all year round, allow the public to steer a ship, set sails and navigate using classic and modern navigational instruments without getting wet, cold or too seasick. The Holoship project aims to primarily use existing technology to create an immersive experience with great learning perspectives for both children and adults.
